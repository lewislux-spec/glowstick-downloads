## Opening GlowStick

Mac: unzip the download and open GlowStick.app, or move it to Applications.
Windows: extract the entire ZIP, keep its folder contents together, then open
GlowStick.exe. These downloads are packaged apps, not installer wizards.

The Mac apps are ad-hoc signed, not Apple-notarized. Windows is not
Authenticode-signed. Operating-system trust warnings may appear.

The Apple Silicon app was opened locally. The Intel package passed startup
checks under Rosetta. Native Windows and physical Intel Mac playback still
require testing on those machines.

[Previous releases](https://github.com/lewislux-spec/glowstick-downloads/releases)
remain available for rollback. Checksums are included with each new release.
